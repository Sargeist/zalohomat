# Автообновление статусов

## Что делает `/api/cron/refresh`

1. **Пересчёт всех статусов** с временным затуханием. Без этого статус «стареет»
   только когда кто-то откроет карточку — а надо, чтобы вчерашнее «работает»
   само превращалось в «неизвестно».
2. **Проверка доступности магазина** через Google Places (если задан
   `GOOGLE_PLACES_API_KEY`): открыт ли сейчас, не закрыт ли временно или
   навсегда. За один прогон проверяются 60 самых давно не проверявшихся точек,
   чтобы не выжечь квоту.

## Чего он не делает

**Не определяет, сломан ли сам автомат.** Такой телеметрии в публичном доступе
не существует ни у кого. Она есть у операторов — TOMRA, Envipco, Botler —
внутри их систем, и получить её можно только партнёрством, не запросом к API.
Поэтому статус машины стоит и будет стоять на отчётах людей и на кабинете
магазина, когда ты его сделаешь.

Автоматика даёт три вещи: свежесть (старое само гаснет), «магазин закрыт»
(тогда автомат недоступен независимо от исправности) и «закрыто навсегда»
(точку пора убирать с карты).

## Расписание

Vercel Hobby разрешает только один запуск в сутки — `vercel.json` настроен
на 03:00 UTC. Этого хватает для сверки с Google Places.

Для пересчёта каждые 15 минут нужен внешний планировщик. Бесплатно:

1. **cron-job.org** → Create cronjob
2. URL: `https://твой-домен.vercel.app/api/cron/refresh`
3. Schedule: every 15 minutes
4. Advanced → Headers: `Authorization: Bearer <твой CRON_SECRET>`

Endpoint — обычный HTTP-роут, ограничение действует только на планировщик
самого Vercel, не на маршрут.

## Переменные

```
CRON_SECRET=<случайная строка>          # обязательно, иначе роут открыт всем
GOOGLE_PLACES_API_KEY=<ключ>            # опционально
SUPABASE_SERVICE_ROLE_KEY=<ключ>        # обязательно для этого роута
```

Внимание: как только добавишь `SUPABASE_SERVICE_ROLE_KEY` в Vercel, ключ
с правами обхода RLS начинает жить на сервере. Это нормально и необходимо
для крона, но следи, чтобы он не попал ни в один клиентский файл —
префикса `NEXT_PUBLIC_` у него быть не должно никогда.

## Проверка вручную

```powershell
curl.exe -H "Authorization: Bearer ТВОЙ_СЕКРЕТ" https://твой-домен.vercel.app/api/cron/refresh
```

Ответ:
```json
{"ok":true,"statuses_refreshed":6,"availability_checked":0,"places_enabled":false}
```
